# recognize pack 8k —— 8S2P / 总负载 200A 工况（重点考察环流）

> 使用 `ecm_pack` 可重构电池包仿真库完成的「拓扑热切换 + 组间环流」工况演示。
> 脚本：`demo_8s2p_200a.py`；结果图：`ecm_pack_8s2p_200a.png`；数值数据：`ecm_pack_8s2p_200a.csv`。

## 工况设定

| 参数 | 值 |
|------|-----|
| 拓扑 | 支路 A（8S）先单独工作 → t=360s 后支路 B 并入 → **8S2P** |
| 总负载 | **200A**（电流控制，全程恒定） |
| 电芯 | **314Ah 大电芯**（R0=R1=0.4mΩ, τ=100s；尺寸 174×71.7×207mm） |
| 初始 SoC | 全部 **1.0** |
| 时间线 | Solo 360s + 并入后 600s，dt=1s，共 960 步 |

## 核心结果（环流）

| 指标 | 数值 | 说明 |
|------|------|------|
| 并入瞬环流峰值 | **139.71 A** | B→A 方向合闸涌流/环流 |
| 支路 A 瞬时电流 | **−39.71 A**（被充电） | B 的 EMF 远高于 A，A 被反向充电 |
| 支路 B 瞬时电流 | **239.71 A** | 承担全部负载 + 给 A 充电的环流量 |
| 末段稳态环流 | **10.43 A** | SoC 差驱动的慢速均衡尾流 |
| 环流衰减 τ（全段） | **329 s** | RC 恢复(100s) + SoC 均衡混合尺度 |
| 环流衰减 τ（尾部） | **912 s** | 纯 SoC 被动均衡时间尺度 |
| SoC Δ（并入瞬间） | **0.0633** | B=1.000 vs A=0.9365 |
| SoC Δ（600s 后） | **0.0396** | 收敛中（负载持续放电致收敛较慢） |

## 物理解读

并入瞬间 **~140A 合闸涌流** 来自两支路 **EMF 差 ≈ 0.84V**：
- OCV 差（B SoC=1.0 vs A 0.9365）≈ **0.22V/组**；
- **RC 极化失配占主导**：A 已以 200A 放电 360s，RC 极化 v_rc 被"耗尽"至 ≈ −0.62V/组；
  B 闲时待机、RC=0、OCV 全额可用 → 额外 ≈ 0.62V 差。
- 组间环阻仅 ≈ **6.4mΩ**（两组各 ~3.2mΩ），故 I = ΔE/R_loop ≈ **140A**。

> ⚠️ **工程警示**：这是真实 BMS 风险——接触器合闸冲击电流可达 140A，通常需要预充电路或限流缓冲。

环流方向始终 **B→A**（高 EMF 的 B 给低 EMF 的 A 充电 / 减缓 A 放电，实现被动均衡）。
双时间尺度：前段 RC 恢复（τ≈100s）快速跌至 ~25A；后段 SoC 差驱动慢速均衡（τ≈900s）缓慢衰减至 ~10A。
